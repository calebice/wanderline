# Working in Wanderline

Read `CODEX.md`, `README.md`, `docs/PROJECT_STATE.md`, and `docs/README.md` before making changes.

For any frontend, UX, styling, or interface-copy work, also read `docs/DESIGN_SYSTEM.md` and
`docs/UI_REGRESSIONS.md`. Open the live design reference at `/internal/design-system` when reviewing
visual changes. The artwork teaching guides are not the application design system.

The owner approved Garden Studio revision 04: paper A and Pigment edge controls. Reuse these
patterns without additional approval. New patterns or departures require a concrete proposal and
owner approval; update the live reference and written contract together. Preserve the entire
Feeling First selector (appearance, slider, labels, sticky placement, and scrolling behavior)
and the frozen Simple Recipe v1 presentation, content, assets, and printing.

## Task workflow

- Give each task a short, human-readable title based on the feature or work in progress. Update the
  title when the task's scope becomes clear or materially changes.
- When Plan mode is enabled for a task, move that task to the **Backlog** sidebar section.
- When the owner approves the plan for implementation, move the task to **Now** before making
  changes.
- When implementation and verification are complete, stage all in-scope changes and move the task
  to **Review**. Do not stage unrelated changes or move blocked or unverified work to Review.
